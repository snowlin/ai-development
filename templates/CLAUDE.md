# Claude Code 项目说明

开始任何任务之前，请先读取并遵守项目根目录的：

- `AGENTS.md`
- `PROJECT.md`

同时根据当前任务读取相关项目文档：

- `docs/project-map.md`
- `docs/architecture.md`
- `docs/data-flow.md`
- `docs/decision-log.md`
- `docs/learning-notes.md`

## 执行要求

1. `AGENTS.md` 是本项目的主要 AI 开发协议。
2. 本文件不重复维护完整规则。
3. 如果本文件与 `AGENTS.md` 冲突，以 `AGENTS.md` 为准。
4. 修改代码之前，先根据 `PROJECT.md` 和 `AGENTS.md` 执行 IPSI-G 检查。
5. 如果产品定义、系统数据流或验收标准不清楚，先输出分析，不要写代码。
6. 除非用户明确要求，否则不要立即修改代码。
